# skill-segretaria

Skill `segretaria` per **DeepSeek Harness**: un assistente personale che archivia le chat, tiene la memoria tra le conversazioni, gestisce scadenze e promemoria, prepara i file da stampare senza mai stampare da solo, organizza orario e verifiche di scuola.

È la versione **base**, senza dati personali: si adatta alle proprie cose.

## Come si installa

1. Installa DeepSeek Harness Desktop (gratis): https://www.deepseek.com/harness/ — c'è per Windows e macOS.
2. Scarica `SKILL.md` (pulsante *Download raw file* in alto a destra, oppure tasto destro → *Salva con nome*).
3. Nella cartella dei dati di Harness crea `skills/segretaria/` e metti dentro il file chiamandolo `SKILL.md`.
4. Apri una chat e scrivi `/segretaria` seguito da quello che ti serve.

## Cosa contiene

- regole non negoziabili (soldi, stampe, messaggi a terzi, privacy);
- memoria e indice delle chat;
- archivio chat, coda stampe, scuola, dashboard e promemoria;
- come si verifica e si riporta un lavoro fatto.

Si può modificare liberamente: è un file di testo.
